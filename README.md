### 📹 [CCTV Camera Control](https://github.com/salah-ayash/cctv-camera-control)

**Flutter-based CCTV monitoring and management application**

Developed core streaming and playback functionality during my internship at Bumi Terus ITS Sdn. Bhd., then independently enhanced the application with account management, an Android release, and an interactive web demo.

**Key Features**
- Live RTSP camera monitoring
- Recorded video playback by date
- Authentication and user profile management
- Android application and web demo

**Technologies:** `Flutter` `Dart` `RTSP` `VLC` `PHP` `MySQL`

[View Repository](https://github.com/salah-ayash/cctv-camera-control)
